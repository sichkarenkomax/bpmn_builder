# BPMN Studio v0.1

Первый публичный релиз редактора: схему можно смоделировать, оформить, обсудить и
выгрузить в шесть форматов.

## Что вошло

- Редактор BPMN 2.0 на bpmn-js: темы, стили, дорожки, пулы, этапы, комментарии,
  Markdown-документация, кастомные атрибуты, закрепление элементов.
- Round-trip XML без потери чужих расширений; XSD-валидация и одна проверка
  сохранения на один PUT.
- Экспорт:
  - SVG и PNG 1×/2×/4× (прозрачный фон);
  - PDF A4/A3, альбомная/портретная ориентация, многостраничный;
  - BPMN XML, JSON-модель, CSV/XLSX-реестр, DOCX-паспорт процесса.
- Шаблоны нового документа: пустой, согласование, онбординг, закупка.
- Сохранение: обязательный `If-Match`, потоковый лимит 5 МиБ, 428/409/413,
  один PUT на документ, черновики в IndexedDB.
- API: rate limiting по IP/токену, таймауты, security headers/CSP, лимит тела.
- Production-профиль Docker: статический frontend за nginx, non-root, без
  `--reload`, закреплённые образы, закрытый Swagger, порты только на loopback.
- Ленивая загрузка редактора: начальный экран не тянет `bpmn-js` (≈89 КБ gzip
  против ≈215 КБ gzip в чанке редактора).

## Проверки

- `make check`: ruff, mypy strict, pytest, tsc, eslint, vitest, prettier.
- `npm run build`.
- Playwright: редактор, документация, этапы, стили, типы атрибутов и экспорт.

## Ограничения

- Аутентификации и ACL пока нет: API открыт на запись до этапа 4.
- Вложения и гиперссылки на элементах — этап 4.8.
- Rate limiting хранится в памяти процесса; для нескольких воркеров нужен Redis.
- PDF собирается из PNG текущего холста, а не headless Chromium: текст в PDF
  растровый. Векторный PDF — в следующем релизе.
- Внешние изображения в Markdown разрешаются только через
  `VITE_MARKDOWN_IMAGE_HOSTS` и CSP.
