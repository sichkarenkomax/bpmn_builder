# PR: этап 3 — симуляция токена (`v0.3`)

Ветка: `feature/overlay-layout-polish` → `main`.
Заголовок для GitHub:

> Этап 3: исполняемая симуляция токена и выпуск v0.3

## Что входит

- Движок токена: старт/концы, задачи, exclusive/parallel/inclusive/event-based
  шлюзы, условия без `eval`, таймеры, `max_steps`, счётчики, `decision` с ручным
  выбором ветки.
- Переменные прогона: снимок на каждом шаге, `changed`, скрипт-задачи
  `имя = выражение`.
- Подпроцессы: разбор/сериализация/reconcile вложенных элементов; исполнение
  свёрнутого одним шагом и раскрытого через внутренние старты/концы,
  вложенность ≥2, общие переменные, прерывающие и неразрушающие boundary-таймеры,
  перехват ошибки скрипта граничным `errorEventDefinition`.
- Сохранённые прогоны (`simulation_run`) с лимитом 20 на диаграмму и тест-кейсы
  (`test_case`) с привязкой к `version_id`, редактированием и pass/fail-diff;
  миграции `0003` и `0004`.
- Панель «Симуляция»: журнал, шаги, переменные, тепловая карта, сохранение
  прогона, создание/запуск/удаление тест-кейсов; содержимое прокручивается при
  уменьшении высоты, блоки не наезжают друг на друга.
- План после `v0.3`: редизайн оболочки без холста (3.6), модульный фундамент
  (4.0) и модули wiki/задачи/чаты (5.5) в `docs/ROADMAP.md`.
- Релиз `v0.3`: версия 0.3.0, `docs/releases/v0.3.md`, README, ROADMAP, HANDOFF.

## Известные ограничения

- Не моделируются компенсация, событийные подпроцессы, multi-instance и
  граничные события сообщений/сигналов; error boundary ловит только сбой
  скрипт-задачи.
- Скрипт-задачи — только безопасные присваивания, без JS/Groovy-рантайма.
- Старые тест-кейсы без `version_id` запускаются по текущей версии.
