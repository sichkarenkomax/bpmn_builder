# ADR-004. Совместная работа: блокировки по элементам + presence

- **Статус:** принято (пересмотр по триггерам ниже)
- **Дата:** 12.11.2026
- **Задача:** 0.7

## Контекст

Цель — несколько человек в одной диаграмме: видеть друг друга, комментировать,
не затирать правки. Два подхода:

1. **CRDT** (Yjs / `pycrdt`): полное реальное совместное редактирование, офлайн-мерж,
   но нужен мост между моделью bpmn-js и CRDT-документом (сложно, много краевых случаев
   с удалением пулов, переносом между дорожками, DI-координатами).
2. **Блокировки**: элемент захватывается на время правки, остальные видят «занято»;
   просто, предсказуемо, укладывается в модель «диаграмма = XML-документ».

## Решение

Для v0.4:

- **Presence** — WebSocket + Redis pub/sub: кто онлайн, курсоры, выделение.
- **Правка на уровне элемента**: клиент захватывает элемент (`POST /lock {elementId}`),
  сервер держит TTL 30 с с продлением; чужие правки этого элемента блокируются в UI.
- **Сохранение** — whole-document PUT с обязательным `If-Match: <etag>`; отсутствие
  заголовка → 428, несовпадение → 409 и понятное «схема изменилась, обновите».
- **Комментарии** — не требуют блокировок, пишутся сразу (отдельная таблица).
- **Версии** — снапшот на каждое сохранение, восстановление одним действием.

CRDT не внедряем, пока не появится требование офлайн-редактирования или одновременной
работы над одним элементом (например, совместное редактирование текста подписи).

## Триггеры пересмотра

- нужен офлайн-режим с последующим мержем;
- более 5 редакторов в одной диаграмме одновременно;
- жалобы «не могу подвинуть элемент, он занят» становятся системными;
- появляется совместное редактирование текстов (описания, скрипты).

## Последствия

- Этап 4 оценивается в 6 недель, а не 10+: CRDT-мост не входит в скоуп.
- Конфликты возможны на уровне «документ целиком» — снимаются etag-проверкой и
  короткими сессиями автосохранения.
- Если позже переходим на CRDT, таблицы `diagram_version` и API сохраняются:
  CRDT-документ становится внутренним состоянием, XML — материализацией.
