Это идеи на будущее. Вставляй их реализацию в те этапы roadmap, где считаешь это наиболее целесообразным. Если сталкиваешься со сложностями или нужны уточнения - спрашивай. Смотри этот файл регулярно, после каждого нового запроса пользователя, даже если новые идеи не упомянуты.

# Дополнительно к этому файлу

- Записанные или уже реализованные пункты добавлять в роадмап, но отсюда удалять

Для комментариев при клике на элемент через ПКМ, в меню должно быть доступно "Добавить комментарий". Для предупреждений: можно сделать как с комментариями - отображать значок соответствующего цвета рядом с элементом. Это должно активироваться и выключаться в панели вверху (можно рядом с комментариями). Еще у нас нет граничащих событий! Если что-то ты можешь сделать быстро - делай. Остальное - в roadmap
