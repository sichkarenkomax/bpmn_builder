# HANDOFF — передача между агентами (Freebuff ↔ OpenCode)

> Живой документ для последовательной работы двух агентов над одним проектом.
> Правило: **кто заканчивает сессию — обновляет этот файл** (состояние, что сделано, что дальше, блокеры).
> Кто начинает — читает его первым.

## Протокол

1. Перед началом работы: прочитать `docs/HANDOFF.md`, `docs/ROADMAP.md`, затем при необходимости проверить последние логи Freebuff в `/root/.config/manicode/projects/bpmnSoft/chats/bpmnSoft/chats/*` (см. пути ниже).
2. Во время/в конце работы: обновить разделы «Текущее состояние», «Что сделано в этой сессии», «Следующие шаги», «Блокеры/риски».
3. Переключение агент выполняет **по явному сигналу пользователя** (автоматического триггера нет). Пользователь говорит: «Freebuff закончил — подхвати» / «проверь Freebuff» или наоборот.
4. Статусы задач в `docs/ROADMAP.md` менять только по факту выполнения DoD (как описано в roadmap).

- Как читать: сообщения лежат в `session_message` (`type` = `user`/`assistant`/`idle`, JSON в `data`),
  части — в `session_part`. У `user` текст в `data.text`, у `assistant` — массив `data.content`
  с блоками `text` / `reasoning` / `tool`. Время — epoch ms.

```bash
python3 - <<'PY'
import sqlite3, json
con = sqlite3.connect('file:/root/.local/share/opencode/opencode.db?mode=ro', uri=True)
con.row_factory = sqlite3.Row
sid = 'ses_e2e69e326ffe5a5IOrTkyuqSpd'
for r in con.execute("select type, seq, data from session_message where session_id=? order by seq", (sid,)):
    d = json.loads(r['data'])
    if r['type'] == 'user':
        print('USER:', d.get('text', ''))
    elif r['type'] == 'assistant':
        print('AGENT:', ' '.join(c.get('text', '') for c in d.get('content', []) if c.get('type') == 'text'))
PY
```

> Примечание: `~user/.local/share/opencode/opencode.db` — старая база (октябрь, другой окружение),
